# 💼 JobTrack - Job Application Tracker

JobTrack is a responsive web application that helps users manage and track their job and internship applications in one place.

## 🚀 Live Demo

https://riyathakre6265-cloud.github.io/jobtrack-job-application-tracker/

## ✨ Features

- Add job and internship applications
- Edit existing applications
- Delete applications
- Track application status
- Search applications by company or role
- Filter applications by status
- Dashboard with application statistics
- Success rate progress bar
- Data persistence using LocalStorage
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages
